What's inside the reference build

Six documented modules, each written to demonstrate a specific external-overlay technique.

👁️

ESP Wallhack

Box and name ESP rendered through an external overlay — a study of screen-space projection and entity reading.

🎯

Aimbot Logic

FOV-based target selection and smoothing math, exposed as readable code for learning aim-assist fundamentals.

🦴

Skeleton Overlay

Bone-chain rendering that illustrates how player skeletons are parsed and drawn over the game window.

📡

Radar

A compact 2D radar showing entity positions relative to the local player — great for spatial-math practice.

Setup

How it works

Three steps from download to a running educational instance.

1

Download & extract

Grab the latest release from gitscore.cc and extract the archive into a clean folder. Everything is self-contained — no installers, no background services.

2

Run the injector

Launch Deadlock in windowed or borderless mode, then run the included injector and point it at the provided DLL to attach the external overlay.

3

Study the overlay

Toggle ESP, skeleton, aimbot and radar from the in-app panel. Read the annotated source alongside it to understand each technique in practice.

Questions

Frequently asked

Everything you need to know before you download.

Is this actually a cheat? +
It is a reverse-engineering reference project. The code demonstrates external overlay techniques for educational study. Using it in live matches violates Deadlock's terms of service — the intent is learning, not competitive play.
What does it include? +
Four modules — ESP wallhack, aimbot logic, skeleton overlay and radar — plus a documented DLL injector and fully annotated source code, all packaged for Windows 10 and 11.
Is it free and open source? +
Yes. The full source is published and free to download from gitscore.cc. You can read, fork and modify every line to deepen your understanding of external overlay development.
Will it work on my system? +
It targets Windows 10 and Windows 11 on x64. Run Deadlock in windowed or borderless mode. The injector requires standard user permissions; no kernel drivers are involved.
